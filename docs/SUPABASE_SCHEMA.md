# Supabase Schema

## 1. 总体说明

本项目后续使用 Supabase 保存咨询、报名、预约、订单和 Demo CRM 线索。当前代码已提供无新增依赖的 REST 写入封装：当 `NEXT_PUBLIC_SUPABASE_URL` 与 `NEXT_PUBLIC_SUPABASE_ANON_KEY` 缺失时，表单自动使用 mock fallback，不会导致页面崩溃。

## 2. 环境变量

```env
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
```

注意：

- `SUPABASE_SERVICE_ROLE_KEY` 只允许服务端使用。
- 不要提交 `.env.local`。
- 不要把真实密钥写入代码。

## 3. 快速执行脚本

当前项目对应的最新 SQL 已整理在：

```text
docs/SUPABASE_SETUP.sql
```

在 Supabase Dashboard -> SQL Editor 中复制执行该文件内容即可。

## 4. SQL 建表语句

```sql
create table if not exists public.contact_inquiries (
  id bigint generated by default as identity primary key,
  name text,
  contact text,
  customer_type text,
  project_type text,
  budget text,
  timeline text,
  description text,
  service text,
  status text not null default 'new',
  created_at timestamptz not null default now()
);

create table if not exists public.course_signups (
  id bigint generated by default as identity primary key,
  name text,
  wechat text,
  plan text,
  platform text,
  goal text,
  status text not null default 'new',
  created_at timestamptz not null default now()
);

create table if not exists public.beauty_bookings (
  id bigint generated by default as identity primary key,
  service_name text,
  booking_date text,
  booking_time text,
  customer_name text,
  phone text,
  note text,
  first_visit boolean default true,
  status text not null default 'pending',
  created_at timestamptz not null default now()
);

create table if not exists public.private_orders (
  id bigint generated by default as identity primary key,
  items jsonb,
  total_amount numeric default 0,
  customer_name text,
  phone text,
  wechat text,
  address text,
  expected_delivery text,
  note text,
  group_buy boolean default false,
  status text not null default 'pending_contact',
  created_at timestamptz not null default now()
);

create table if not exists public.student_project_posts (
  id bigint generated by default as identity primary key,
  title text,
  category text,
  price text,
  condition text,
  contact text,
  location text,
  description text,
  status text not null default 'new',
  created_at timestamptz not null default now()
);
```

## 5. 推荐索引

```sql
create index if not exists contact_inquiries_created_at_idx on public.contact_inquiries(created_at desc);
create index if not exists course_signups_created_at_idx on public.course_signups(created_at desc);
create index if not exists beauty_bookings_created_at_idx on public.beauty_bookings(created_at desc);
create index if not exists private_orders_created_at_idx on public.private_orders(created_at desc);
create index if not exists student_project_posts_created_at_idx on public.student_project_posts(created_at desc);
```

## 6. RLS 策略建议

MVP 可先允许匿名 insert，禁止匿名 select/update/delete。

```sql
alter table contact_inquiries enable row level security;
alter table course_signups enable row level security;
alter table beauty_bookings enable row level security;
alter table private_orders enable row level security;
alter table student_project_posts enable row level security;

create policy "anon can insert contact inquiries" on contact_inquiries for insert to anon with check (true);
create policy "anon can insert course signups" on course_signups for insert to anon with check (true);
create policy "anon can insert beauty bookings" on beauty_bookings for insert to anon with check (true);
create policy "anon can insert private orders" on private_orders for insert to anon with check (true);
create policy "anon can insert student project posts" on student_project_posts for insert to anon with check (true);
```

后台管理读取建议后续加 Supabase Auth 后再开放，不建议匿名读取真实客户数据。

## 7. 前端插入字段

- `contact_inquiries`：`name`、`contact`、`customer_type`、`project_type`、`budget`、`timeline`、`description`、`service`
- `course_signups`：`name`、`wechat`、`plan`、`platform`、`goal`
- `beauty_bookings`：`service_name`、`booking_date`、`booking_time`、`customer_name`、`phone`、`note`、`first_visit`、`status`
- `private_orders`：`items`、`total_amount`、`customer_name`、`phone`、`wechat`、`address`、`expected_delivery`、`note`、`group_buy`、`status`
- `student_project_posts`：`title`、`category`、`price`、`condition`、`contact`、`location`、`description`

## 8. 本地开发注意事项

没有 Supabase 环境变量时，表单会进入演示模式并显示提示；这适合本地预览和客户演示。

## 9. 上线部署注意事项

在 Vercel 配置 `NEXT_PUBLIC_SUPABASE_URL` 和 `NEXT_PUBLIC_SUPABASE_ANON_KEY` 后，表单会尝试写入 Supabase。上线前请先在 Supabase SQL Editor 执行本文件 SQL。

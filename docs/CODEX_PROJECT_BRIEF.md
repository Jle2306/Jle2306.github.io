# 2\. 项目核心目标

我要开发一个用于自媒体平台获客和接单的网站。

这个网站不是普通简历站，而是一个 **接单转化型作品集网站**。

网站要让潜在客户快速理解：

1. 我能为哪些客户服务
2. 我能开发哪些网站和轻量系统
3. 我有哪些可演示 Demo
4. 每类 Demo 能解决什么商业问题
5. 大概多少钱起
6. 如何联系我
7. 我不是单纯写代码，而是帮客户做能展示、能获客、能预约、能报名、能收订单、能管理客户的小系统

# 5\. 技术栈要求

推荐技术栈：

* Next.js
* TypeScript
* Tailwind CSS
* Supabase
* Vercel

开发要求：

1. 使用 Next.js App Router
2. 使用 TypeScript
3. 使用 Tailwind CSS 做样式
4. 组件放在 `src/components`
5. 页面放在 `src/app`
6. 数据配置放在 `src/data`
7. 工具函数放在 `src/lib`
8. 类型定义放在 `src/types`
9. 文档放在 `docs`
10. 表单后期接入 Supabase
11. 不要把任何密钥写死到代码里
12. 必须保证移动端适配
